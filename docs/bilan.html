Se préparer à l’examen

L’évaluation finale est un examen écrit sur table. Voici les types d’exercices attendus :

Types de questions fréquentes

  1. Question de définition (4–6 pts) — Définissez le coût d’opportunité / l’externalité / le bien public
  2. Analyse de document (6–8 pts) — Commentez un graphique ou tableau statistique
  3. Question de réflexion (8–10 pts) — Présentez les arguments pour et contre une politique économique
