1. Mesurer le chômage

La définition du BIT

Selon le Bureau International du Travail, est chômeur toute personne qui :

  1. Est sans emploi sur la semaine de référence
  2. Est disponible pour travailler dans les deux semaines
  3. A effectué des démarches actives de recherche dans le mois précédent

2. Les types de chômage

Type Définition Politique adaptée
Frictionnel Entre deux emplois (transition normale) Améliorer l’information sur le marché
